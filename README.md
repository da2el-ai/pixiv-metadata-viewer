# pixiv Metadata Viewer

pixivのPNG画像にマウスホバーするとメタデータを表示。

## インストール方法

`dist/` フォルダをChromeの機能拡張管理画面にドロップする。

### アップデート方法

機能拡張管理画面から削除し、その後インストールし直す。

## 機能概要

- PNGInfo、NovelAI、StableDiffusion Forge/reForge の埋め込みメタデータを表示
- ページに表示されている全ての画像をメタデータの有無をチェック
  - 処理が重くなるかもしれないので無効にできます
  - 手動でチェックすることも可能
  - 上記切り替えは設定パネルから変更
- メタデータパネルの「▲/▼」ボタンで表示位置変更
- 「×」ボタンで非表示
- 機能拡張アイコンをクリックすると設定パネル表示
